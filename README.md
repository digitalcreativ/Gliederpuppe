# Gliederpuppe

Eine digitale Holz-Gliederpuppe in 3D, die man im Browser posieren kann.

- Körperteil anklicken und ziehen bewegt das Gelenk (16 Kugelgelenke)
- Regler für genaues Einstellen (Beugen, Seitlich, Drehen)
- Posen: Grundhaltung, Gehen, Laufen, Sitzen, Nachdenken, Winken, Knien, Jubeln, Verbeugen
- Animationen: Gehen, Laufen, Winken
- Seiten tauschen, Zufallspose, Rückgängig (Ctrl+Z)
- Eigene Posen speichern (im Browser)

Läuft komplett im Browser, ohne Installation. Three.js wird von cdn.jsdelivr.net geladen.

## Benutzen

`index.html` im Browser öffnen oder über GitHub Pages veröffentlichen.
